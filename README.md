# CardioVision 3D - Dataset Placement Instructions

Track A requires the **UCI Extension of Z-Alizadeh Sani Dataset**.

## Instructions
Please place the raw dataset file (`Z-Alizadeh_sani_dataset.xlsx` or `Z-Alizadeh_sani_dataset.csv`) inside this directory:

```
data/Z-Alizadeh_sani_dataset.xlsx
```
or
```
data/Z-Alizadeh_sani_dataset.csv
```

Once placed, run the audit notebook `ml/notebooks/01_dataset_audit.ipynb` to complete Step 1.
